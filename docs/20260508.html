Boris 眼中的编码未来
💥Coding is Solved
Boris 自己 100% 用模型写代码，一天提交多达 150 个 PR。Claude Code 团队全员写代码——工程经理、产品经理、设计师、数据科学家、财务、用户研究员，人人都会。Anthropic 全公司不再有手写代码，所有 SQL 全部由模型生成。两年前还有点像 type-ahead（按 Tab 补全一行），现在已经是完整的 Agent 写全部逻辑了。
🔄Loops：永远在线的 Agent
Boris 日常跑着 几十个 /loop 循环任务：自动 rebase PR、修复 flaky test、每 30 分钟抓取 Twitter 反馈并聚类。Claude 4.7 已经开始 主动提议开 loop——"我注意到数据在变化，让我开个循环每 30 分钟给你发 Slack 报告。"

Loops 和子 Agent 正在取代传统的 CI/CD 流水线。
📜印刷术的软件版本
印刷术前欧洲识字率仅 10%，印刷术后 50 年出书量超过此前千年。书价跌了 100 倍。几百年后全球识字率升到 70%。软件正在经历完全一样的民主化——而且只会更快。以前需要学 TypeScript 和框架才能写代码，以后只需要懂业务。

● 灵魂拷问 03 / 03
当编码不再是瓶颈，
什么决定胜负？
● 答案
转换成本和流程优势被 AI 削弱了——模型自己能理解和执行流程，随时可以从一个工具迁移到另一个。但 网络效应、规模经济和稀缺资源 仍然坚挺。

新的稀缺资源是 跨学科通才：兼懂产品+设计+工程+数据科学的人。而最大的结构性机会属于 从零开始拥抱 AI 的创业公司——它们没有组织惯性的包袱。

"这是最好的创业时代。小团队可以构建与大公司同等价值的产品，因为大公司需要花 5 年迁移到云端，而你只需要一个 prompt。"
