TRAINING DATA

Waymo 联合 CEO Dmitri Dolgov：
2000 万次出行与全面自动驾驶之路

端到端+α 架构：Waymo Foundation Model 是端到端模型，但在 learned representation 之上增加结构化中间表征，用于运行时验证、闭环训练与强化学习的丰富奖励函数。 世界行动语言模型：多模态 world-action-language model，集成 driver / simulator / critic 三大支柱，融入 VLM 通用世界知识。 指数级扩张：第一个全自动运营到 4 个城市用了 8 年；2026 年一天之内同时在 4 个城市推出服务。2000 万次出行中最后 1000 万次仅用 7 个月。 第六代硬件：与 Zeekr（极氪）合作的新平台已开始员工全自动运营，内部空间"像客厅一样宽敞"。 行业周期：每次技术突破（CNN、Transformer、LLM）重塑早期曲线，但不会改变问题的长尾本质。
●●● WHY IT MATTERS

Waymo 的"端到端+结构化中间表征"架构为自动驾驶规模化提供了关键路线图，也为其他 AI 系统如何平衡端到端学习的灵活性与工程可验证性提供了重要参考。

// 技术博客
ANTHROPIC ENGINEERING

Claude Code Auto Mode：更安全的免审批模式

两级分类架构：Stage 1 快速单 token 过滤器（8.5% 误判率），触发后 Stage 2 chain-of-thought 推理降至 0.4% 误判率。 代理间注入防护：输入层 prompt-injection probe + 输出层 transcript classifier，双重防护。 Deny-and-continue：阻断时不中断，尝试更安全的替代路径。3 次连续阻断或 20 次总阻断后终止。 危险操作召回率约 83%：17% 漏检率。Anthropic 坦诚"如果你在认真手动审批每个操作，auto mode 可能是退步。"
●●● WHY IT MATTERS

用运行时分类器取代二元审批，为 agentic AI 的安全规模化提供了一条可操作的路径。

当 Waymo 的自动驾驶实现指数级扩张，Claude Code 的 auto mode 让 AI 代理自主运行大部分操作， 而中国芯片正在将 AI 算力推向发展中国家 —— 2026 年正在成为"AI 规模化落地"之年。 问题不再是"AI 能做什么"，而是"我们如何信任它规模化"。 Waymo 的答案是用结构化验证补充端到端学习，Anthropic 的答案是用分类器取代人工审批。 两种不同的信任机制，指向同一个未来。
