基础设施层的两个信号
📈定制模型才是真正的推理市场
Tuhin 透露了一个反直觉的事实：Baseten 上 95%+ 的 token 来自定制模型，而非跑开源原始权重。

客户在做三件事：自有数据 post-training 微调、编译优化、从原始模型蒸馏出专用小模型。

"没有人只是跑 vanilla 开源权重"——因为推理经济的利润不在跑模型，而在适配模型。
"如果一个模型能让推理成本降低 80%，我们却因为地缘政治而不用它，那对美国创新是巨大的损失。" — Tuhin 谈 DeepSeek
🧠Anthropic 的"大脑-双手"解耦
同一天，Anthropic 公开了 Managed Agents 的核心架构：将"大脑"（Claude + harness）、"双手"（sandbox + 工具）和"session 日志"拆成三个独立接口。

效果炸裂：p50 首 token 延迟下降 60%，p95 下降 90%+。更重要的是，token 不再放在 sandbox 中——prompt injection 即使骗过 Claude 也拿不到凭证。

这是 "为尚未想到的程序设计接口"——像操作系统用 process/file 抽象活了几十年一样。

应用层的护城河在哪？
● 答案
应用层不会消失——壁垒在用户信号（user signal）。

Tuhin 用 Abridge（医疗 AI 记录）举例：他们对医院工作流的深度集成、电子病历系统的对接、合规认证——前沿模型公司根本无法复制。

Baseten 收购 Parzed 团队的逻辑也印证了这一点：推理 → 产生数据 → 评估 → post-training 微调，形成完整闭环。应用层积累的用户信号，就是训练下一轮模型的弹药。
