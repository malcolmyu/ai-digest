● 观点解析 02 / 03
为什么 HTML 比 Markdown 更适合 AI 输出？
📈三条输出范式进化论
Karpathy 划出了一条清晰的路径：纯文本（费力难读）→ Markdown（当前默认，加粗/斜体/表格）→ HTML（正在成形的新默认，灵活布局/图形/交互性）→ ... → 交互式神经视频/模拟（终极形态）。

每个阶段都在让信息更符合人脑的视觉处理特性。HTML 是当下最实用的一步——今天就能用，不需要等技术成熟。
🧠视觉是人脑的"10 车道高速公路"
"Audio 是 AI 偏好的输入方式，但 vision（图片/动画/视频）是偏好的输出方式"。

人脑约 1/3 的皮层 是专门处理视觉的大规模并行处理器。HTML 比 Markdown 更接近这种视觉化沟通的本质——排版、布局、色彩、SVG——都是信息。
"hot tip: try ask for HTML" — Karpathy 的实用建议

● 灵魂拷问 03 / 03
HTML 之后，
AI 输出的终点是什么？
● 答案
终点不是 HTML——是交互式神经视频。但 HTML 是 AI 输出从"文字对话"进化到"视觉呈现"的关键一跃，而且今天就能用。

Karpathy 清楚地画出了路线：text → markdown → HTML → ... → 交互式神经视频/模拟。在等待全实时神经渲染成熟之前，HTML 是最实用的中间态——它让 AI 用视觉语言表达，比 Markdown 丰富 10 倍。本质是：HTML 的灵活性和表现力，让 AI 的输出密度和质量上了一个台阶。
